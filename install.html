Install the FunClient Bookmarklet

This adds a button to your bookmarks bar that launches FunClient in a new window (max sized) and attempts fullscreen.

Desktop install (fast)

Drag this button to your bookmarks bar:

🚀 Launch FunClient DRAG ME
If you don’t see the bookmarks bar: Ctrl + Shift + B (Windows) or ⌘ + Shift + B (Mac)
If the new window doesn’t open, your browser blocked popups — allow popups for centralschool.fun.

Mobile install (iOS / Android)

  1. Bookmark this page first.
  2. Edit the bookmark.
  3. Rename it to FunClient (optional).
  4. Replace the URL with the code below.
  5. Save. Tap the bookmark to launch.
